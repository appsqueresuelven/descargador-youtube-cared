# Descargador de YouTube - CARED

Aplicación de escritorio desarrollada en **Python + PySide6** para descargar videos individuales y audio de YouTube de forma sencilla, con una interfaz compacta y moderna.

## Características

- Descarga de videos individuales.
- Permite pegar varios enlaces, uno por línea.
- Limpia automáticamente parámetros innecesarios de los enlaces.
- Descarga en:
  - MP4 Universal
  - MP4 rápido
  - WEBM
  - MP3
- Calidades disponibles:
  - 4K
  - 1080p
  - 720p
  - 480p
- MP4 Universal con **H.264 + AAC** para mayor compatibilidad.
- Selección de carpeta de descarga.
- Cola de descargas.
- Barra de progreso.
- Porcentaje de descarga.
- Velocidad de descarga.
- Tiempo transcurrido y tiempo restante.
- Historial de descargas.
- Descargas simultáneas configurables.
- Interfaz desarrollada con PySide6.
- Diseño inspirado en los colores de YouTube.

## Requisitos para ejecutar el código fuente

- Python 3.12 recomendado
- PySide6
- yt-dlp
- FFmpeg

Instala las dependencias de Python con:   pip install -r requirements.txt

```bash
pip install -r requirements.txt
FFmpeg debe estar instalado en el sistema o encontrarse junto al programa.

## Versión para Windows

La versión portable para Windows estará disponible en la sección **Releases**.

Esta versión estará preparada para funcionar sin necesidad de instalar Python.

## Uso

1. Copia el enlace de un video de YouTube.
2. Pégalo en la aplicación.
3. Selecciona el formato y la calidad.
4. Elige la carpeta de destino.
5. Pulsa **DESCARGAR**.

También puedes pegar varios enlaces, uno por línea.

## Compatibilidad

Para equipos antiguos, autoradios o dispositivos con compatibilidad limitada se recomienda:

**MP4 Universal - H.264 + AAC**

Para computadoras y dispositivos modernos se puede utilizar:

**MP4 rápido**

## Aviso

Utiliza esta herramienta únicamente para descargar contenido propio, contenido con permiso del autor o material cuya descarga esté permitida.
